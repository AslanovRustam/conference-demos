# Clickable Plinko 3D (C3)

Офлайн-игра Plinko на WebGL для ноутбука и телефона. Дизайн: `docs/2026-10-30-c3-plinko-3d-design.md`, план: `docs/plans/2026-10-30-c3-plinko-3d-plan.md`.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm test         # юнит-тесты
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

Бренд (логотип, цвета, шрифты) берётся из `shared/brand/` через алиас `@brand`.
