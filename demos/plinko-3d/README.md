# Clickable Plinko 3D (C3)

Офлайн-игра Plinko на WebGL для ноутбука и телефона. Дизайн: `docs/2026-10-30-c3-plinko-3d-design.md`, план: `docs/plans/2026-10-30-c3-plinko-3d-plan.md`.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm test         # юнит-тесты (vitest)
npm run e2e      # сквозные тесты (Playwright: собирает и запускает preview на :4173)
npm run build    # сборка в dist/
npm run preview  # просмотр сборки, http://localhost:4173
npm run icons    # пересобрать иконки PWA из public/icon.svg
```

Бренд (логотип, цвета, шрифты) берётся из `shared/brand/` через алиас `@brand`. Сборка копирует всё нужное в `dist/`, поэтому после сборки `shared/` не нужен.

## Показ на конференции

**Ноутбук.** `npm run build && npm run preview`, открыть http://localhost:4173 в Chrome, кнопка полноэкранного режима в верхней панели. Интернет не нужен.

**Телефон.** `dist/` выкладывается на любой статический хостинг (пути относительные, подпапка тоже подходит). Один раз открыть ссылку при интернете, после этого игра работает без сети:
- Chrome на Android: меню → «Установить приложение» (откроется на весь экран);
- Safari на iPhone: «Поделиться» → «На экран Домой».

**Как играть.** Заставка → тап → игра. DROP, пробел или тап по пирамиде бросают шарик. 100 BALLS запускает дождь. Пока шарики летят, риск и ряды переключить нельзя.

**Режим ведущего** (посетитель не увидит):
- `Shift+B` — следующий брошенный шарик попадёт в Big или Mega Win;
- `Shift+R` — бесплатные 100 шариков;
- на телефоне и ноутбуке: удерживать логотип 2 секунды → панель с теми же двумя кнопками.

**Attract.** Через 45 секунд без касаний игра играет сама: демо-шарики, крупный выигрыш, дождь. Баланс при этом не меняется. Первое касание возвращает в игру и само шарик не бросает.

## Параметры адреса

| Параметр | Что делает |
|---|---|
| `?seed=123` | детерминированные исходы (для тестов и повторяемых показов) |
| `?quality=high` / `?quality=light` | закрепить уровень качества, автопереключение выключается |
| `?debug=1` | счётчик FPS (только для разработки) |
| `?embed=1` | режим для лобби C4: без заставки, кнопка EXIT отправляет `postMessage({ type: 'clickable:exit' })` |

## Производительность

Уровень качества выбирается сам: телефоны, планшеты и слабые GPU начинают с облегчённого (без преломления в кристаллах, упрощённая постобработка). Дальше `PerformanceMonitor` следит за FPS: если высокий уровень проседает, игра переходит на облегчённый, а затем снижает разрешение.

Замер на машине разработки (Intel UHD Graphics, production-сборка, Chromium с GPU, DPR 1). Цифры неточные: во время замеров на машине параллельно работали другие сессии, и даже пустая страница давала 59 FPS.

| Уровень | Экран | Простой | Дождь 100 шариков |
|---|---|---|---|
| high | 1920×1080 | 30 | 23 |
| light | 1920×1080 | 45 | 28 |
| high | 1366×768 | 48 | 31 |
| light | 390×844 @3x | 53 | 38 |

Вывод: на встроенной графике Intel 1080p идёт на облегчённом уровне, и автопереключение это делает само. Окончательно проверять нужно на устройстве, на котором будет показ (чек-лист ниже).

## Чек-лист перед показом на реальном устройстве

- [ ] Одиночные броски плавные, шарик не дёргается.
- [ ] Дождь из 100 шариков без заметных рывков.
- [ ] Звук: звон по рядам музыкальный, дождь звучит каскадом, а не шумом, музыка тихая и нарастает в замедлении.
- [ ] Звук возвращается после блокировки экрана и разблокировки.
- [ ] Mute работает и запоминается после перезагрузки.
- [ ] Поворот телефона: пирамида целиком видна, интерфейс не перекрывает её.
- [ ] Установка на экран «Домой» и запуск в авиарежиме.
- [ ] Режим ведущего: Shift+B / Shift+R на ноутбуке, удержание логотипа на телефоне.
- [ ] Attract включается через 45 секунд и выключается касанием.
