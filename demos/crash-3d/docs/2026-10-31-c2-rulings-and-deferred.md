# C2 Crash: решения исполнителя и отложенные мелочи

Полный список из журнала исполнения плана `docs/plans/2026-10-30-c2-crash-plan.md` (журнал удалён после финального ревью, история остаётся в git). Строки оставлены как в журнале, на английском. Формат решения: что решено, почему, во что обойдётся, если решение неверное.

## Решения (Rulings), в порядке принятия

- Ruling R1: controller already ran `git init` in demos/crash-3d, created .gitignore (plan entries + `.superpowers/sdd/`) and branch feat/c2-crash; Task 1 keeps them — avoids clobbering the SDD workspace — cost if wrong: none, entries are a superset.
- Ruling R2: `params.freeze → engine.freezeAt` and a provisional debug-only `window.__crashReady = true` (after `document.fonts.ready` + first HUD render) are wired in Task 4/5 so Task 5's verification shots work; Task 6 moves `__crashReady` to "scene loaded + 30 frames" — plan put both in 6 but 5 needs them — cost if wrong: trivial rewiring.
- Ruling R3: `engine.setAttract(true)` resets balance to START_BALANCE, bet to DEFAULT_BET and auto off (history kept); Task 3 adds a test — spec §6 says the balance resets on entering attract, the plan named no API for it — cost if wrong: small engine change in Task 18.
- Ruling R4: the "red only for …" Global Constraint governs the HUD; in-world red (parachute sectors, confetti, explosion flash) is allowed — spec mandates brand-red confetti and red flash — cost if wrong: recolor a texture.
- Ruling R5: stageFloat continuity test starts `prev` at -1 (plan bug) — fix test to `let prev = stageFloat(1)` and loop from m = 1.001 — the test's intent (continuous, strictly increasing) is unchanged — cost if wrong: none.
- Ruling R6: "floored to cents" test compares floats with toBe (plan bug) — assert `Math.abs(x * 100 - Math.round(x * 100)) < 1e-6` — same intent — cost if wrong: none.
- Ruling R7: with anchor [1, 0.97] floor2 maps u∈(0.96,0.97) to 1.00 too, so ~4% explode instantly vs spec §7 "~3%" — change the first anchor to [1.01, 0.97] (u ≥ 0.97 → exactly 1.00; continuous part starts at 1.01; survival(x)=0.97 for 1 ≤ x < 1.01) and keep the test expecting 0.03 — spec number wins over plan formula; all other anchors untouched — cost if wrong: a one-constant change.
