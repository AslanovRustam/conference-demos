# C1 «Clickable Vault»: 3D-слот, дизайн

Дата: 2026-10-30. Концепция: C1 из `docs/concepts.md`. Общие требования оттуда действуют полностью.

## Что согласовано с заказчиком

- Тема: **банковский сейф**. Бонус-раунд проходит в **золотом хранилище** внутри сейфа.
- Визуал по референсам заказчика (третья итерация): узнаваемая круглая дверь банковского хранилища на стальной стене с заклёпками, внутри золото, никакого неона. Неоновый «киберсейф» первых двух итераций заказчик отклонил: «выглядит не как сейф, а как коробка со спинами, неон слишком яркий».
- **Старт игры — закрытый сейф и кнопка «Open the vault»**, по нажатию дверь открывается и начинаются спины (требование заказчика).
- Каждый 5-й спин без бонуса открывает бонус с джекпотом (требование заказчика, см. «Механика»).
- Где играют: на ноутбуке представителя или на телефоне посетителя по QR-коду. Кто именно нажимает Spin, не важно.
- Остальное заказчик отдал на усмотрение исполнителя («ок, делай»). Все решения ниже, кроме двух пунктов выше, приняты исполнителем.

## Решения исполнителя

### Платформа и сборка
- Vite + TypeScript + React 19 + three.js / R3F / drei + @react-three/postprocessing + GSAP + Motion + zustand (стек из каталога).
- **Без Howler.** Музыка и SFX синтезируются кодом через Web Audio API (`src/audio/`). Причины: ни одного аудиофайла, полная работа офлайн, малый вес для телефона, звук реагирует на игру (питч растёт с каскадом, музыка открывается на крупных выигрышах). Модуль изолирован, его можно заменить записанными файлами, не трогая игру.
- **Без Rapier.** Каскады анимируются по заранее рассчитанному результату, физика не нужна.
- **Без troika-текста.** Подписи ламп множителя рисуются в canvas-текстурах браузером: troika не читает WOFF2, а Montserrat в бренде есть только в WOFF2.
- Один статический билд для ноутбука и телефона, `base: './'`, работает из любой папки и в iframe лобби. `dev` и `preview` запускаются с `--host`: телефоны в сети стенда открывают игру по IP ноутбука без интернета. Публичный хостинг и QR — отдельный шаг.

### Бренд
- Всё берётся из `shared/brand/` через alias `@brand`: логотип, шрифты Clickable Black (крупные цифры и заголовки) и Montserrat (остальной текст), токены `--ck-*`, favicon, фирменный срез угла кнопки (`.ck-chamfer`).
- Векторного знака в бренде нет, поэтому золотые слитки штампуются первой буквой «C» из логотипа.
- На Windows alias из примера в `shared/brand/README.md` не резолвится (обратные слеши в пути). В `vite.config.ts` путь обёрнут в `normalizePath`. Другим демо понадобится то же.
- Язык интерфейса английский (стандарт слотов и международных конференций).

### Механика
- Поле **6×5**, выплата **«в любом месте»**: 8+ одинаковых символов где угодно на поле.
- **Каскады:** выигрышные символы взрываются, верхние падают вниз, сверху досыпаются новые. Повторяется, пока есть выигрыш.
- **Множитель серии** (шкала ламп на автомате): ×1, ×2, ×3, ×5, ×8, ×12, ×20, ×30, ×50. Сбрасывается на каждом спине.
- **Скаттер** (кодовый диск сейфа): 3+ на итоговом поле запускают бонус. 3 → 10 фриспинов, 4 → 12, 5+ → 15. Ретриггер в бонусе: +5.
- **Бонус:** своя шкала ×1, ×2, ×3, ×4, ×5, ×6, ×7, ×8, ×10, ×12, ×15, ×20, ×25. Множитель не сбрасывается между фриспинами и растёт весь бонус.
- **Бонус планируется целиком при входе** и всегда даёт не меньше 15× ставки, то есть всегда заканчивается празднованием Big Win. После долгого входа через дверь сейфа пустой бонус убил бы впечатление.
- **Гарантированный бонус-шоу (по просьбе заказчика):** если 5 спинов подряд бонуса не было, 5-й спин открывает сейф. Такой бонус, как и принудительный бонус ведущего (`Shift+B`), идёт ровно 10 фриспинов без ретриггеров и даёт не меньше 200× ставки. Значит, празднование доходит до верхней ступени **JACKPOT** с дождём монет по всему экрану и подписью «The vault is yours». Счётчик сбрасывается после любого бонуса и для нового посетителя.
- Фриспины идут в 1.3 раза быстрее обычных спинов, чтобы бонус укладывался примерно в минуту.
- Символы по возрастанию ценности: изумруд (ступенчатая огранка), сапфир (кушон), аметист (груша), топаз (овал), золотая монета с буквой «C» и гуртом, ключ от сейфа с рубином, стопка слитков, бриллиант. Скаттер — кодовый диск сейфа.
- Ставки 10, 20, 50, 100, 200, 500 (по умолчанию 100). Старт 100 000 кредитов. Если баланс меньше ставки, он автоматически пополняется.
- Выплаты хранятся в десятых долях ставки, поэтому все выигрыши целые.
- Big / Mega / Epic Win / Jackpot: от 15×, 40×, 100× и 200× ставки.
- **Первый спин нового посетителя** (после заставки или attract-режима) выбирается из выигрышей ≥5× ставки минимум с двумя каскадами.
- Результат спина считается целиком заранее (сетка, все каскады, выигрыши), анимация только проигрывает его. Математика покрыта тестами (`src/game/engine.test.ts`).
- **Баланс демо** (симуляция, 20–40 тыс. спинов): RTP базовой игры ≈ 0.80, бонуса ≈ 0.78, итого ≈ 1.6. Выигрыш в 42% спинов, бонус примерно раз в 39 спинов, в среднем около 30× ставки до гарантии минимума. Это намеренно щедро: деньги виртуальные, баланс посетителя должен медленно расти.

### Сцена и ВАУ-моменты
История визуала: первая версия («детский, нет 3D, нет ярких анимаций») и вторая (неоновый автомат) отклонены заказчиком. Действующая версия — банковское хранилище по референсам заказчика:
- **Комната:** стена из крупных стальных листов с заклёпками, глянцевый плиточный пол (на `high` зеркальный), прожекторы на дверь, над дверью табличка с логотипом Clickable. Рельеф швов и заклёпок нарисован прямо в текстуре 2048 px (канавка с бликом, купол с тенью): карта рельефа (bump) давала «плывущие» швы при движении камеры. На плане двери камера почти неподвижна, покачивание включается по мере подхода к барабанам.
- **Дверь сейфа** (вся процедурная, `scene/vault/Door.ts`):
  - корпус: ступенчатая лицевая плита, кольца, латунные заклёпки, радиальные рёбра (логотип только на табличке над дверью, на самой двери его нет — по просьбе заказчика);
  - управление: штурвал из 8 спиц с шарами-рукоятями, объёмный кодовый замок на приподнятой бобышке между рукоятями штурвала (хромированная выпуклая оправа с рельефной красной меткой, диск с рифлёным пояском и наклонной гравированной шкалой 0–90, рифлёная ручка с куполом);
  - механика: 12 хромированных запорных ригелей по кромке, тяги на внутренней стороне;
  - петля: монтажная плита с болтами на стене, высокий шкворень с куполами, пять чередующихся кулаков (три от двери, два от стены), кованые рычаги, привинченные к двери латунными болтами.
- **Два варианта материала:** серебряная сталь (по умолчанию) и латунь/бронза (`?look=brass`).
- **Внутри:** круглый проём обрамляет барабаны, как иллюминатор. Символы обрезаются плоскостями, которые идут от камеры через внутреннюю кромку рамки барабанов (пересчёт каждый кадр). Поэтому крутящиеся ленты и падающие символы уезжают ровно за рамку, а не обрываются посреди видимой подложки. Панель со слотами стоит сразу за символами (−0,6 от их плоскости) и продолжается вверх и вниз за край рамки примерно на полклетки. Камера смотрит в окно сверху, и при глубокой или короткой коробке её освещённое дно видно полосой под барабанами: символы проезжали поверх этой полосы, прежде чем скрыться под рамкой. К краям панель темнеет, у рамки получается тень. Барабаны стоят в стальной рамке с заклёпками, слоты подсвечены тёплым светом изнутри, над ними табличка со шкалой множителя. По бокам полки со слитками. Свет внутри зависит от того, насколько открыта дверь.
- **Старт:** закрытая дверь, кнопка «Open the vault» (нажать можно в любом месте экрана), по шву двери пробивается золотой свет. По нажатию:
  1. проворачиваются кодовый диск и штурвал, уходят ригели;
  2. дверь выдвигается из проёма и распахивается на петле (заходит за прямой угол, к стене);
  3. хлещет золотой свет, камера переходит от плана «дверь» к плану «игра» у проёма;
  4. сразу идёт первый спин.
- **Символы — 3D-сокровища.** Огранённые камни (изумруд, сапфир, аметист, топаз, бриллиант) со светящимся ядром. На `high` камни настоящие преломляющие (transmission, у бриллианта дисперсия), на `medium`/`low` — полупрозрачная огранка поверх ядра. Ещё золотая монета с гуртом и «C», ключ от сейфа с рубином, стопка слитков. Тело камня тёмное, чтобы яркий свет комнаты давал блики, а не пастельную заливку.
- **Запуск спина:** тёплый «лазер охраны» сканирует окно, золотые «кометы» падают в барабаны, по рамке навстречу друг другу бегут два огонька, из центра расходится световое кольцо. Барабаны разгоняются со смазом и защёлкиваются слева направо с перелётом, вспышкой и искрами.
- **Напряжение:** если на поле 2 скаттера, оставшиеся барабаны тормозят по одной с золотым лучом (промежуточные по 0.65 с, последний 1.35 с), камера наезжает, звучит райзер.
- **Выигрыш:** поле затемняется вуалью, выигрышные символы вылетают к камере и крутятся, между ними бьют молнии в цвет символа. Затем вспышка, искры, осколки, ударные кольца, «удар» камеры. Новый множитель («×3») влетает в кадр и улетает в шкалу.
- **Вход в бонус:** скаттеры празднуют, дверь захлопывается (камера отъезжает), запирается, по шву пробивается золото, дверь открывается снова, и внутри уже золотое хранилище (штабели слитков на полу, тёплый свет сильнее, лампы золотые). Выход из бонуса устроен так же.
- **Надписи выигрыша** — металлические буквы в стиле премиальных слотов: тёмная грань и выдавленная глубина, градиент полированного металла, бегущий блик, мерцающие искры вокруг. Big — золото, Mega — рубин, Epic — платина, Jackpot — золото с красной гранью. Суммы стоят на тёмной пластине с золотой кантовкой и заклёпками; в том же стиле баннеры фриспинов, тост каскада и «×N».
- **Big / Mega / Epic / Jackpot:** фонтан чеканных монет из проёма, на джекпоте ещё и дождь монет сверху, ускоряющийся счётчик, смена ступеней с ударом, тряска, вспышки.
- **Кнопка Spin — маленький сейфовый замок:** кольцо из шлифованной стали с латунными заклёпками, тёмный пояс со шкалой (медленно вращается, во время спина быстро), выпуклый глянцевый купол с бликом и пробегающей полосой света. При нажатии купол вдавливается, а стальное кольцо с пружинкой проворачивается на одно деление. В бонусе купол золотой.
- Bloom и виньетка мягкие: свет реалистичный, неона нет.
- Голографическое окно (C8) в эту итерацию не вошло.

### Режимы
- **Attract** через 45 с простоя (время, пока идёт спин, бонус или празднование, простоем не считается): дверь закрывается и запирается, камера медленно облетает закрытый сейф, снова появляется «Open the vault». Касание или клавиша открывают сейф для нового посетителя: свежий баланс и показательный первый спин.
- **Режим ведущего:** `Shift` + клавиша по физической раскладке (работает и на русской). `B` — бонус, `W` — большой выигрыш, `R` — сброс баланса, `F` — FPS, `A` — attract, `Q` — качество, `H` — панель. Если спин уже идёт, принудительный исход применяется к следующему. На телефоне панель ведущего открывается долгим (2 с) нажатием на логотип.
- **Embed** (`?embed=1`): кнопка выхода, которая отправляет `postMessage({ type: 'clickable:exit' })`. Стартовый экран тот же (закрытый сейф): он же нужен как жест пользователя, без которого браузер не включит звук.
- **Полный экран:** кнопка рядом со звуком, как в plinko-3d (`requestFullscreen` на всю страницу). Иконка меняется на «свернуть», состояние следит за `fullscreenchange`, поэтому `Esc` тоже учитывается. В лобби разворачивается фрейм игры (у него `allow="fullscreen"`). Если `document.fullscreenEnabled` ложно (Safari на iPhone, фрейм без разрешения), кнопка не показывается.
- Параметры: `?quality=low|medium|high` (фиксирует качество), `?look=brass` (латунная дверь), `?presenter=1` (панель ведущего сразу открыта, авто-качество выключено).

### Производительность
- Три уровня качества:
  - `high` — для ноутбука с дискретной видеокартой: DPR до 2, зеркальный пол, преломляющие камни, размытие фона, больше частиц;
  - `medium` — для телефонов и встроенной графики;
  - `low` — для слабых устройств.
- Уровень определяется один раз при старте: тач-экран, маленький экран или встроенная графика Intel (UHD/Iris) — `medium`, иначе `high`. `?quality=high` включает полный вариант принудительно, ведущий может переключить уровень вручную.
- Автоподстройка во время игры меняет только разрешение рендера (шаги 1 / 0.8 / 0.65), а не эффекты. Новое значение применяется в момент запуска следующего спина: смена размера холста на кадр очищает его, а вспышка запуска это скрывает. На стартовом экране автоподстройка выключена: первые секунды уходят на компиляцию шейдеров, и любая смена там видна как моргание.
- Экран загрузки снимается только после того, как отрисовалось окружение и все шейдеры сцены скомпилированы заранее (`compileAsync`). Иначе компиляция подвешивала затухание заставки, и оно пропадало рывком.
- Экономия на `high`: вместо MSAA сглаживание SMAA (убирает «лесенки» на тонких кромках на всех уровнях), проход преломления и отражение пола в половинном разрешении.
- Полноэкранные прозрачные слои (вуаль, вспышки, развёртка) не рисуются, пока прозрачны.
- Частицы — один пул `Points` с собственным шейдером, осколки и монеты — `InstancedMesh`, молнии — переиспользуемые ленты. Модели символов переиспользуются через пул.
- Замер на встроенной Intel UHD (ноутбук разработчика), 1600×900: `medium` 57–60 FPS, `high` около 27 FPS. Поэтому на такой графике по умолчанию стартует `medium`.
- Порты закреплены за демо (dev 5181, preview 4181), чтобы не конфликтовать с другими играми, запущенными на том же ноутбуке.

### Раскладка
- У камеры два плана: «дверь» (закрытый сейф целиком) и «игра» (барабаны через проём). Для каждого она сама подбирает дистанцию и смещение, чтобы кадр не заходил под HUD при любом соотношении сторон.
- Горизонтальный экран: проём по центру, открытая дверь у стены слева, HUD снизу. Вертикальный (телефон): проём во всю ширину, табличка с логотипом над ним, большая кнопка Spin снизу.

## Что не входит
- Реальные деньги, ставки, регистрация.
- Публичный хостинг и генерация QR.
- Голографическое окно через веб-камеру.
- Записанная музыка и SFX (модуль готов к замене).

## Как проверено
- `npm test`: 19 тестов движка (выплаты, каскады, лестницы множителей, скаттеры, принудительные исходы, план бонуса, показательный спин, баланс по симуляции).
- В изолированном headless Chromium с GPU прогнаны сценарии: спин, Big/Mega Win, полный бонус от ожидания скаттера до возврата в сейф, attract-режим и выход из него, телефон 390×844, embed. Ошибок в консоли нет.
- Production-сборка открывается без единого внешнего запроса, то есть работает офлайн.
- **Не проверено:** звук на слух (уровни выставлены по измерениям), реальные телефоны (iOS Safari, Android Chrome), целевой ноутбук стенда.
