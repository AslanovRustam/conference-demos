# Clickable Vault — 3D-слот (C1)

Банковский сейф: на старте закрытая дверь и кнопка «Open the vault», дверь распахивается, внутри барабаны с каскадами и растущим множителем, бонус в золотом хранилище. Только виртуальные кредиты. Решения и их причины описаны в [docs/design.md](docs/design.md).

## Запуск

```
npm install
npm run dev       # разработка: http://localhost:5181, открывается и с телефонов в той же сети
npm run build     # статический dist/
npm run preview   # показ собранной версии (офлайн): http://localhost:4181, тоже доступен в сети
npm test          # тесты математики
```

Нужна папка `../../shared/brand` (общий бренд). Собранный `dist/` от неё уже не зависит.

**Телефоны на стенде без интернета:** ноутбук и телефоны в одной Wi-Fi-сети (свой роутер). `npm run preview` печатает адрес `Network: http://<ip>:4181/`, его и кодируем в QR. Порты закреплены за этим демо, чтобы не конфликтовать с другими играми на том же ноутбуке.

## Режим ведущего

| Клавиши | Действие |
|---|---|
| `Пробел` / `Enter` | спин, пропуск празднования |
| `Shift` + `B` | следующий спин запускает бонус, который заканчивается джекпотом |
| `Shift` + `W` | следующий спин даёт Mega или Epic Win |
| `Shift` + `R` | сбросить баланс |
| `Shift` + `A` | attract-режим сразу |
| `Shift` + `F` | счётчик FPS |
| `Shift` + `Q` | переключить качество графики |
| `Shift` + `H` | панель ведущего с теми же кнопками |

Клавиши работают при любой раскладке. На телефоне панель ведущего открывается долгим (2 с) нажатием на левый верхний угол экрана.

Если 5 спинов подряд не было бонуса, 5-й спин сам открывает сейф: бонус на 10 фриспинов всегда заканчивается празднованием JACKPOT (от 200× ставки). Так у стенда без вмешательства ведущего показывается вся цепочка анимаций.

Через 45 с простоя сейф сам закрывается (attract-режим), камера облетает дверь. Касание открывает его для нового посетителя со свежим балансом.

Кнопка в правом верхнем углу (рядом со звуком) разворачивает игру на весь экран и возвращает обратно; `Esc` тоже выходит. В лобби она разворачивает фрейм игры. Где браузер не даёт странице занять экран (Safari на iPhone, фрейм без разрешения `fullscreen`), кнопки нет.

## Параметры URL

- `?quality=low|medium|high` — зафиксировать качество графики (по умолчанию выбирается автоматически).
- `?look=brass` — латунная дверь вместо стальной.
- `?presenter=1` — сразу открыть панель ведущего.
- `?embed=1` — для лобби C4: кнопка выхода (`postMessage({ type: 'clickable:exit' })`).

## Структура

```
src/game/      математика (engine, config, тесты) и режиссёр спина (director)
src/scene/     3D: сейф (vault/: дверь, комната, материалы), символы, поле, эффекты, камера
src/audio/     синтез музыки и звуков (Web Audio)
src/ui/        HUD, оверлеи, заставка, панель ведущего
src/state/     состояние игры (zustand) и уровни качества
```
